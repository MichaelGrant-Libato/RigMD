# Security Policy

## Supported Versions

The latest release of RigMD is the supported version for security review.

## Reporting a Vulnerability

If you discover a security issue in RigMD, please report it privately to the project maintainers.

Please include:
- a short description of the issue
- steps to reproduce, if possible
- affected area, such as web app, desktop app, installer, or backend service

Please do not publicly disclose the issue until we have reviewed it.

## Scope

This policy covers the RigMD web app, desktop app, installer, and related backend services.
